# Bodoni Moda

Bodoni Moda by Owen Earl (indestructible type*), variable font with optical size and weight (400 to 900) axes. Copyright 2020 The Bodoni Moda Project Authors (https://github.com/indestructible-type/Bodoni). The unmodified font is distributed under the SIL Open Font License 1.1; see [OFL.txt](OFL.txt).

Source: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/bodonimoda), file `BodoniModa[opsz,wght].ttf`, retrieved 11 October 2026 and renamed to BodoniModa-Variable.ttf. With thanks to Owen Earl and to the Google Fonts project for keeping it available.

The library registers this file as the antiqua of its printer's case, for numerals and contrast.
