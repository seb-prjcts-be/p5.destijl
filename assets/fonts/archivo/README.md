# Archivo

Archivo by Omnibus-Type, variable font with width (62 to 125) and weight (100 to 900) axes. Copyright 2020 The Archivo Project Authors (https://github.com/Omnibus-Type/Archivo). The unmodified font is distributed under the SIL Open Font License 1.1; see [OFL.txt](OFL.txt).

Source: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/archivo), file `Archivo[wdth,wght].ttf`, retrieved 11 October 2026 and renamed to Archivo-Variable.ttf. With thanks to Omnibus-Type and to the Google Fonts project for keeping it available.

The library registers this file as the grotesk of its printer's case; the site uses it for headings.
