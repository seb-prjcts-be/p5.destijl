Drawing with p5.merz

Use p5.merz.js and the Merz API.

Load p5.js, then p5.merz.js and your own sketch. The examples use p5.js 2.3.4.

<script src="p5.js"></script>
<script src="p5.merz.js"></script>
<script src="sketch.js?v=api-audit-1"></script>

Function reference lists the calls and their return values. The sections below include options and sketches.

Draw a piece

function setup() {
  createCanvas(400, 300);
  noLoop();
  background(Merz.farbe.grau);
  Merz.riss('R', 150, 100);
}

Pass the material and its position to draw it directly. The library makes the geometry, cuts or raster image it needs. Bauteile shows one short sketch for each operation.

Merz.satz('R', 150, 100);
Merz.bauteile('R', 150, 100);
Merz.bauteil('R', 'bowl', 150, 100);
Merz.ausschnitt('R', 150, 100);
Merz.rundschnitt('R', 150, 100);
Merz.schnitt('R', 150, 100);
Merz.splitter('R', 150, 100);
Merz.riss('R', 150, 100);
Merz.andruck('R', 150, 100);

Each line is a separate drawing. Geometric letters default to size 100 and black. The rectangular cut keeps the upper half; the oval fits the source bounds; the triangular cut keeps the upper-left half. Splitter draws three horizontal strips with an 8-unit gap. Riss and andruck use their fixed default amounts and seeds. Coordinates place the geometry origin or the top-left of the cut output; ordinary text stamps use a baseline.

Options come after x and y, when you need them: Merz.riss('R', 150, 100, { size: 160, color: Merz.farbe.rot }). Color, angle and scale apply to placement; size, weight, proportion, spacing and leading apply when making letters. Riss also accepts amount and seed; andruck accepts ink, paper and seed; splitter accepts rows, columns and gap. In instance mode, pass the p5 instance last: Merz.riss('R', 150, 100, {}, p).

Direct calls return the number of pieces drawn. They also accept prepared geometry, images and fragments for cutting and surface operations. Without drawing coordinates, the calls below return their usual editable data or images. Keep those when you want to reuse material, choose exact cuts or export composition geometry. Direct raster operations process the source on each call; draw static results in setup().

The default colo(u)rs

p5.merz includes five colours, ready to use through Merz.farbe. grau is the background colour at index 0.

  • Grau
  • Rot
  • Schwarz
  • Blau
  • Gelb

Use a name such as Merz.farbe.rot, or its index, Merz.farbe[1]:

function setup() {
  createCanvas(600, 600);
  noLoop();
}

function draw() {
  background(Merz.farbe.grau);
  fill(Merz.farbe.rot);
  rect(40, 40, 120, 80);
}

Change a colour

Pass the colours you want to replace to Merz.settings() in setup(). The other colours keep their defaults:

const farbe = Merz.settings({ rot: '#c4382d', grau: '#f1eddf' });
background(farbe.grau);
fill(farbe.rot);

Use lowercase names and six-digit hex colours. The names and indices stay the same after an override.

Draw with geometry

Merz.satz(text, options) returns normalised text, paths, width and frame height. Each path contains points, an array of [x, y] pairs, and width, its stroke thickness. Choose colour, placement and repetition in your sketch.

const word = Merz.satz('ROOM', { size: 100 });
const pieces = Merz.bauteile('R', { size: 100 });
const bowl = Merz.bauteil('R', 'bowl', { size: 100 });

Merz.bauteile(letter, options) returns an array of named parts: { id, paths }. It accepts one uppercase letter from A to Z. Use satz() for words, numbers and punctuation. Both calls accept the text measurements described below and return fresh data, so changing points does not change the alphabet or another call.

Parts keep their position within the original letter frame. An R has left-stem, bowl and lower-stem; names vary with the construction. Read them with pieces.map(part => part.id). A part may contain a joined frame or stepped shape.

For one named part, use bauteil(). It accepts the same size, weight and proportion options as bauteile(). An unknown name reports the available parts for that letter.

function setup() {
  createCanvas(600, 600);
  background('#f7f7f2');
  noLoop();
  const bowl = Merz.bauteil('R', 'bowl', { size: 160 });
  Merz.stempel(bowl, 80, 80, { color: '#b92d26' });
}

The paths are also available when you want to draw or change the points yourself:

function setup() {
  createCanvas(600, 600);
  background('#f7f7f2');
  noLoop();
  const pieces = Merz.bauteile('R', { size: 160 });
  const bowl = pieces.find(part => part.id === 'bowl');
  translate(80, 80);
  noFill();
  stroke('#b92d26');
  strokeCap(PROJECT);
  strokeJoin(MITER);
  for (const path of bowl.paths) {
    strokeWeight(path.width);
    beginShape();
    for (const [x, y] of path.points) vertex(x, y);
    endShape();
  }
}

Use the same paths with instance methods such as p.vertex(). These calls need no p5 instance themselves. Your own p5 drawing is not recorded for SVG export.

Cut a fragment, change its edge

Use a rectangle, an oval or your own outline. All three accept images, graphics, geometry and letter parts, and return a fragment for riss(), stempel() or bau().

const strip = Merz.ausschnitt(source, 8, 48, 286, 167);
const oval = Merz.rundschnitt(source, 8, 48, 160, 100);
const triangle = Merz.schnitt(source, [[0, 0], [180, 0], [90, 120]]);

ausschnitt(source, x, y, width, height) cuts a rectangle. rundschnitt(source, x, y, width, height) cuts an oval inside the same rectangle; omit height for a circle. Both use the top-left corner in source coordinates, independently of p5 rectMode or ellipseMode. Width and height must be at least 1. The oval uses 64 outline points. Pixels outside the source stay transparent.

const piece = Merz.ausschnitt(source, 8, 48, 286, 167);
const cut = Merz.riss(piece, { amount: 0.3, seed: 17 }).bau();
image(cut, 40, 80);

Split a source into pieces

const pieces = Merz.splitter(word, { rows: 3 });
for (const [row, piece] of pieces.entries()) {
  Merz.stempel(piece, [{ x: 40 + row * 17, y: 80 + row * 100 }]);
}

splitter(source, { rows, columns }) returns equal rectangular cuts, ordered left to right, then top to bottom. Both counts default to 1. Choose positive whole numbers, at most 1024 pieces, with each cell at least one source unit wide and high. It accepts images, graphics, geometry, a letter part or an array of parts. Images use their full width and height. Geometry and letter parts both use the outer bounds of their paths, including stroke width. Empty letter-frame margins and leading or trailing spaces are not included in these cuts. Each fragment retains its source x and y. The source is copied once, so later edits do not change the pieces.

Cell boundaries may be fractional; raster image dimensions round up. For an existing fragment, pass its bau() result to splitter().

schnitt(source, outline) accepts a p5.Image, p5.Graphics, satz(), one named part or an array from bauteile(). The outline is a convex polygon of [x, y] points in the source's coordinates, ordered around its edge. It needs at least three corners, without repeated or collinear corners. Pixels outside the source remain transparent.

const letters = Merz.satz('MERZ', { size: 180 });
const piece = Merz.ausschnitt(letters, 0, 20, letters.width, 110);
const torn = Merz.riss(piece, { amount: 0.7, seed: 17 });
const cut = torn.bau(globalThis, { color: '#b92d26' });
image(cut, 40, 80);

riss() changes the cut edge inward. Amount runs from 0 (the clean cut) to 1; seed selects the pattern. Each call starts from the original outline, even when passed an already torn fragment. The material and crop position stay fixed. This is a geometric edge treatment, not a simulation of paper fibres or ageing. It becomes visible where the cut crosses ink or image pixels.

A fragment stores a copy of its source. Its x and y give the crop origin; width and height are rounded up to whole pixels and remain fixed when torn. outline() returns a fresh copy of the current edge. The output is limited to 16 million pixels.

bau() returns a transparent p5.Image using global p5. bau(globalThis, { color }) converts the fragment to a transparent p5.Image, preserving image density or using the drawing context density for geometry. Use bau(p, { color }) in instance mode. Color applies to geometry; image sources retain their own colours. Create the image once in setup(), then use ordinary p5 image(), translate() and rotate(). Rendering needs a browser and p5; geometry fragments and riss() can be prepared without them.

The fragment output is raster. It is not added to a stored composition or its SVG export. Three examples use the same route.

Small surface differences

const printed = Merz.andruck(inkLayer, { ink: 0.12, paper: 0, seed: 17 });
const sheet = Merz.andruck(paperLayer, { ink: 0, paper: 0.18, seed: 17 });
image(sheet, 0, 0);
image(printed, 0, 0);

andruck(source, options, p) takes a p5.Image or p5.Graphics and returns a new p5.Image. It leaves the source unchanged. In instance mode pass p as the third argument. Make the result once in setup() and draw it with ordinary image(). The operation uses a 2D image.

ink gently reduces coverage, with sparse small losses. paper adds faint warm tonal variation and sparse marks without changing alpha. Keep ink on a transparent layer and paper on its own layer. Applying either operation to a scan treats all its pixels; the library cannot identify the original ink or paper for you.

Both amounts range from 0 to 1. Defaults are ink 0.12, paper 0, seed 17. Set both to zero for a clean snapshot. Always return to the original source when changing values; treating an already treated result compounds the changes. The pattern is fixed for the same dimensions and seed. It belongs to the supplied layer and follows that layer when placed in p5.

andruck() preserves the source pixel density. piece.bau() preserves image density; for geometry and parts it follows the p5 drawing context. A 600 × 600 source at pixelDensity(2) returns a 600 × 600 image with 1200 × 1200 backing pixels. Coordinates and surface marks keep their logical scale. The limit is 16 million physical pixels, so density 2 allows up to 2000 × 2000 logical pixels. Density 2 processes four times as many pixels as density 1. A low-resolution scan does not gain detail from a higher-density display. Resizing the source changes the pattern; resolution-independent export and fields shared across independently cropped fragments remain research. The result is raster and is not included in geometric SVG export.

The implementation runs on the CPU. Up to four surface masks are reused, within a 64 MiB cache. Each call still reads and processes the current source pixels; large images take time even with a cached mask. Exact pixels across different devices are not promised. Compare the clean and light versions.

Keep a composition

Store elements when you want to edit them by id or export their geometry as SVG.

let work;

function setup() {
  createCanvas(600, 600);
  noLoop();
  work = Merz.create({ width: 600, height: 600 });
  work.plane(50, 330, 200, 150, { color: Merz.palette.blue });
  work.line(50, 280, 550, 280, { strokeWeight: 8 });
  work.text('FORM', 50, 90, { size: 100, spacing: 12 });
}

function draw() {
  work.draw();
}

Letters, lines and planes

CallWhat it does
work.text(text, x, y, options)Adds a word or several lines of geometric letters. Returns an id.
work.letter(letter, x, y, options)Adds one character with the same options.
work.line(x1, y1, x2, y2, options)Adds a line between two points, including diagonals.
work.plane(x, y, width, height, options)Adds a filled rectangular plane.

All elements accept color, angle and scale. Colours are six-digit hex values, such as #234b92. Use the supplied palette or choose your own colours. Angles are in degrees and rotate around the element’s origin, independently of the sketch’s angleMode.

For text, x/y is the top-left corner of the letter frame. size is its height (default 100), weight is relative bar thickness (0.05-1, default 0.8), proportion sets width (0.55-1.35, default 1), spacing is the gap between letter frames (default 12), and leading is line spacing (default size × 1.4). Measurements use canvas units. Text is not automatically wrapped or scaled.

The character set includes A-Z, 0-9, spaces, new lines and common punctuation. Lowercase becomes uppercase and accents are simplified. Symbols include &, %, @, #, €, $ and £. Curly quotes become straight quotes and non-breaking spaces become ordinary spaces. Unsupported characters raise an error. The letters are our own contemporary constructions. D/O and U/V have distinct shapes; Q stays inside its frame. The unusual letters still need readability studies with users.

A line accepts strokeWeight (default 4). In an update, x2 and y2 are offsets from x/y, so both endpoints move together. Lines and letter paths have square caps.

Short punctuation marks have narrower frames; spacing remains the extra gap between frames. Zero has an inner mark to distinguish it from O. Slash and backslash use straight steps. Numbers and punctuation are contemporary additions.

Changing an element

const title = work.text('SPACE', 40, 70, { size: 60 });
work.update(title, { color: Merz.palette.red, angle: -90 });
work.move(title, 520, 400);
work.bringToFront(title);
work.sendToBack(title);
work.remove(title);

work.get(id) and work.items() return copies of the settings. Keep ids to edit elements later. clear() removes all elements; new elements receive new ids. Invalid measurements or unknown update options leave the existing element unchanged. Adding order determines which element appears on top.

Drawing and export

Use work.draw() in global mode or work.draw(p) in instance mode. The library preserves p5 drawing settings. The default background is paper white; set background: null to draw over an existing sketch.

Match the canvas size to the composition. SVG uses the composition dimensions and clips at the page edge. External p5 transforms do not appear automatically in SVG. Use the elements’ angle, scale and x/y for matching output. This version draws on a 2D canvas.

work.downloadSVG('composition.svg');
const source = work.exportSVG({ title: 'My composition' });

SVG contains vector paths and colour planes. Each export prefixes its clipping and element ids so exports from the same page can be placed inline together. The element ids returned by get() and items() stay unchanged. No font files are needed. The export is an editable vector image.

Geometry for your own drawing

const word = Merz.satz('FORM', { size: 100, weight: 0.6 });

Returns normalised text, paths, width and frame height. Draw these paths with your own p5 code. The geometry core and SVG export also run without p5.

Stempel

Stamp a word with one call. Choose its position, size and colour; the default font is Archivo Black.

Merz.stempel('rrrt', 28, 98);
Merz.stempel('rrrt', 28, 98, { size: 105, color: farbe.rot });
Merz.stempel('ABFALL KLEBSTOFF MERZBILD', 28, 660, {
  size: 16, font: 'monospace', rows: 4, leading: 20
});

A repeated layout can stay in one call. repeat sets the count, stepX and stepY the distance between copies. offsetX shifts every second copy sideways. Lists of colours, angles or scales repeat in order.

Merz.stempel(pieces, -10, 42, {
  repeat: 10, stepY: 58, offsetX: -150,
  color: [farbe.rot, farbe.schwarz, farbe.schwarz]
});

An array of fragments cycles through the pieces. An array of letter parts still draws the parts together. At most 1024 impressions can be placed in one call. Text can also use these placement options; its rows and leading describe lines within each impression.

For text, x and y locate the left end of the first baseline. Size defaults to 32, rows to 1 and leading to 1.2 times the size. Text uses Archivo Black by default. The library loads its bundled font before setup() in p5.js 2.x when loaded after p5.js. Keep assets/fonts/ next to the library. For a late-loaded library, await Merz.ready() before drawing; for a module without a script URL, pass { fontURL }. Font accepts another loaded font family name. Uppercase and lowercase are drawn as typed. Angle is in degrees. Use stempel(source, x, y, options, p) for one placement. Options are optional in global mode; in instance mode use stempel(source, x, y, {}, p) for the defaults. This short form also accepts geometry, parts and fragments. For several placements, use stempel(source, placements, p). Text settings are restored after drawing. The return value counts placements.

const word = Merz.satz('MERZ', { size: 80 });
Merz.stempel(word, [
  { x: 30, y: 40, color: '#b92d26' },
  { x: 60, y: 180, angle: -8, scale: 1.2 }
]);

Merz.stempel(source, placements, p) draws geometry, a letter part, an array of parts or a fragment at the positions you supply. Each placement needs x and y. Optional settings are angle in degrees (default 0), positive scale (default 1, minimum 0.001) and six-digit hex color (default ink black). The function returns the number of impressions.

Omit p in global mode; pass your p5 instance or graphics buffer otherwise. Your outer transforms remain active and drawing settings are restored afterwards. Geometry keeps its original coordinates; a fragment starts at its cropped top-left corner. Colour applies to paths; image fragments keep their source colours. Fragments are rasterised once per colour within each call. Drawings go straight to the canvas and are not added to a stored composition or its SVG export.

Three complete examples

Merzbilder

async function setup() {
  createCanvas(600, 600);
  noLoop();
  background('#f7f7f2');
  await Merz.merzbilder('001', 40, 60, 140);
}

fundsachen(id, x, y, width) loads and draws a transparent sample by number or name. Width is in canvas units; height follows the original proportions. The image is cached. Use await in async setup() to keep drawing order. In instance mode, pass p as the fifth argument. Drawing uses the current p5 transform and restores drawing settings. To edit or repeatedly draw the material, use const piece = await Merz.merzbilder('001'), then stempel() or bau().

Each item in the catalogue has a transparent PNG download. Letters, numbers and rules also have SVG silhouettes. Keep just the samples you use in your sketch folder. The library can stay at its online URL.

const piece = await Merz.merzbilder('022', {
  url: 'merz-8-cover-nasci-ink.png'
});

url points to your downloaded image, relative to the sketch page. You can also use an absolute image URL. Choose either url for one file or baseURL for a folder. Hosted images need to allow cross-origin loading when used from another site.

const piece = await Merz.merzbilder('001');
Merz.stempel(piece, [{ x: 40, y: 60 }]);

Load a catalogue sample by its fixed number or name. Use an async setup function with p5.js 2.x. The result is a fragment for riss(), stempel() or bau(). Merz.merzbilder.list() returns the entries, dimensions, crop coordinates and source links without loading images.

Keep assets/fundsachen/ next to the library file. If the library is loaded as a module or evaluated without a script URL, provide baseURL or an explicit image url. The library reports the missing base instead of guessing from the page location. To host the images elsewhere, pass { baseURL: 'https://your-site.example/samples/' } with the trailing slash. In instance mode use await Merz.merzbilder('001', {}, p). Images load once per URL and p5 context; each call returns its own fragment. Failed loads can be retried. The default variant: 'ink' loads transparent ink. Choose variant: 'scan' for the original paper or variant: 'svg' for an available SVG silhouette. An unavailable variant raises an error. SVG downloads contain vector paths; loading one through merzbilder() rasterises it at the catalogue dimensions for fragment operations. Use the SVG file directly for vector editing and large-scale output.

Function reference

Options can be omitted unless shown otherwise. Coordinates use logical canvas units. Where a call accepts p, omit it for global mode or pass a p5 instance or graphics buffer.

Merz.satz(text, options)Fresh { text, paths, width, height } data; no drawing. Empty text gives empty paths and zero dimensions. Geometry.
Merz.bauteile(letter, options)

Fragment methods

A fragment has fixed x, y, width and height. Its position refers to the source; its raster image starts at the cropped top-left corner.

CallReturns and behaviour
piece.outline()A fresh array of edge points in source coordinates. Editing these points does not change the fragment.
piece.bau(p, { color })A new p5.Image. Colour defaults to #20201e for paths; image material keeps its own colours. Omit both arguments for global defaults. For a colour in global mode, use bau(globalThis, { color: farbe.rot }). Each call rasterises again, so keep the result for repeated drawing. The limit is 16 million physical pixels. Pixel density.
