Fundsachen

Letters, rules and fragments from Merz. Find an item by number or name. Copy its drawing call, or download a PNG or SVG for your own files.


Choose a number and draw it in async setup(). Width sets the size; the proportions stay the same. Choose Downloaded file to use your own copy.

Draw a Fundsache

async function setup() {
  createCanvas(600, 400);
  noLoop();
  background('#f7f7f2');
  await Merz.fundsachen('001', 40, 40, 70);
  await Merz.fundsachen('001', 180, 70, 105);
}

Numbers and names identify the same item. Transparent PNG keeps ink variation. SVG gives a traced, flat-colour silhouette. Original scan keeps the paper.
