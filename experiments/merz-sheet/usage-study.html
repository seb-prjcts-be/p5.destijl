Contexts and layers

Two ways to choose where a stamp is drawn. These helpers belong to this study.

A target in each call

UsageStudy.target(bowl, 30, 45, { color: farbe.rot, target: p });

A context chosen once

const merz = UsageStudy.bind(p);
merz.stempel(bowl, 30, 45, { color: farbe.rot });

A bound context shortens repeated calls. A target option keeps each call explicit when switching between layers.

A layer drawn with p5

const ink = UsageStudy.layer(p, 300, 300, { ink: .12, seed: 17 }, layer => {
  const merz = UsageStudy.bind(layer);
  merz.stempel(bowl, 30, 45, { color: farbe.rot });
  layer.rect(30, 235, 210, 6);
});
p.image(ink, 0, 0);

The helper creates the buffer, preserves density and removes the buffer when drawing finishes. Paper and ink stay separate; ordinary image() calls decide their order. The drawing callback is synchronous.

Left: explicit buffer management. Right: the layer helper with a bound context.
