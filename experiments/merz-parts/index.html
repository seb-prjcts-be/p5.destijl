What the geometry gives us

The current A has a separate crossbar path. We inspected that path and used it directly. Other letters join several bars in one path, so this index is not a general way to name parts. A useful alphabet module would need to make that distinction explicit.

Stored elements make whole-word editing short. Geometry gives ordinary p5 control over available paths. Neither route currently names individual bars. This example keeps that question visible.
